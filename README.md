# 作文小帮手 MVP

面向小学三、四年级的校内同步作文工具。纯 HTML/CSS/JavaScript，无 AI、无后端，无需安装依赖，可离线使用。读音与汉字释义词库随项目一起提供。

## 直接运行

双击 `index.html` 即可使用。推荐通过本地静态服务器访问，学习记录会保存在同一个访问地址下：

```sh
node serve.cjs
```

打开 http://127.0.0.1:4173 。关闭服务时按 Ctrl+C。

## 已实现

- 首页选择三、四年级、上下册及目录版本，按单元展示习作目录。移除右侧装饰框和面向孩子的目录核对说明。
- 原版三、四年级上下册各8个单元位置，包含综合性学习任务；修订版三、四年级上册各8次习作。修订版下册尚未核对完整，明确提示，可切换原版参考目录。
- 每个目录课题都能查看训练重点、专属写作路线。综合性学习不强制按300字作文安排。
- 所有48个目录位置均接入分步训练，覆盖34种课题（版本间同题复用课程）。每课有自己的选择方向、纸上任务、分段范例与完整范例。
- 散文类完整约300字框架和自编范例；诗歌按画面分行，不要求凑字数，综合性学习保留活动与分享要求。
- 全程可点击的思维导图。写作阶段显示中心主题与三条主枝，分清开头、中间和收尾；卡片有写作顺序、字数参考、已选素材、关键词和准备状态。人物重点事例进一步显示起因、动作和对话、结果；书信、诗歌、表达想法、实验采用对应分组。
- 人物、外貌、开头、2—3个特点逐一引导，每个特点有观察角度和专属词句。
- 一件重点事例：特点关联、场景选择、写作顺序判断、纸上关键词提示。
- 感受及结尾的选择引导。
- 日记、连续观察、书信、实验、图画续写、景物、游记、资料介绍、童话和发明想象分别采用对应的路线；书信有格式提醒，资料介绍要求核对来源，图画任务对照孩子自己的课本。
- 三年级上册按用户提供的蒋军晶《超级作文本》PDF中的教学方法设计交互：人物线索、日记小镜头、故事接力、故事山、观察放大镜、景物中心与小景点、现象与理由、经历与心情线。讲解、语言卡和范例为本站原创，不附带PDF或扫描页。
- 选择内容后展开相应词句卡，选2—4张再照着连接好的分支在纸上标记；移除单关键词输入和纸上完成确认勾选。水边可继续选水面/岸边/小动物，四季可继续选春夏秋冬，后两处景物会显示对应的词句。
- 每枝的字数参考由对应范例的汉字数量取近似值（误差不超过2字），同时标明范例实际字数；完整范文按相同的段落与字数展示。
- 写作模式随时回看各段素材、提示、选过的词句和对应分支，所选语言卡会显示在全篇思维导图中。
- 自动保存、刷新恢复、自查、打印框架与当前段提示、手机布局。
- 按课题和教材版本分别保存素材，返回目录保留所选年级、册次和版本；旧版本人物草稿迁移到原版三下《身边那些有特点的人》。
- 取消整页注音，三、四年级均可选中文字查小字典。气泡显示所在句子的读音、字义，以及匹配到的课堂词语简释；多音字可展开其他读音。提供手动输入一个字的查询入口。释义较长时默认显示简短预览，可展开更多。
- 用鼠标拖选文字，手机长按选中文字，自动弹出小字典。普通点击继续选择答案、切换节点；移除查字模式开关。可选择短词查看已有课堂词语解释。旧答案和关键词保留；准备完成状态按新词句卡条件重新核验，不自动替孩子选择词句。

自由表达在纸上完成，网页不生成孩子的整篇作文，也不自动判定纸上内容或字数。范文用于理解写法。

## 放置方式与视觉依据

检查的仓库：

- https://github.com/ico0018/guwen_leyuan ：静态 HTML/CSS/JS，内容 TXT/JSON，已有古文、默写和朗读模块。
- https://github.com/ico0018/hanzi_garden ：静态 HTML/CSS/JS，无 package.json，教材 TXT，本地保存，Vercel 根路径跳转 welcome.html。

作文训练和两者的教材数据、笔顺及朗读状态独立，故选择单独项目 `zuowen_helper`，避免改动现有学习入口。现有组件都是业务耦合的原生页面，没有可直接导入的共享组件库；复用汉字乐园的 CSS 色值、app-shell/topbar 圆角卡片布局、选择按钮及本地记录方式，结合古文乐园的浅绿提示卡片。浏览器核对 xuebabangbang.cn 的米白、浅绿、浅黄卡片及砖红品牌色。

上线时上传本目录全部 HTML、CSS、JS 文件和完整 vendor/ 文件夹；无需构建。serve.cjs 和 verify*.cjs 只用于本地服务与检查，不必上传。独立代码仓库为 https://github.com/ico0018/zuowen_bangbang ，可从学霸帮帮工具首页添加入口。

## 文件

- index.html、catalog-app.js、catalog.css：年级、册次、版本、作文目录和课题详情。
- catalog.js：课本目录、稳定课题 ID、每课目标及写作路线。
- trainer.html：分步训练页面骨架与导航。
- topic-setup.js：训练课题配置、素材保存键与旧草稿迁移。
- styles.css：响应式、视觉及打印样式。
- content.js：人物课程节点、特点词库和范文。
- app.js：选择、进度、导图及保存逻辑。
- course.html、course-app.js、course.css：其他题型的分步训练、导图、保存和写作回看。
- courses.js：32种其他课程的原创任务与分段范例。按课题标题匹配，可继续加入新课程。
- dictionary-support.js、dictionary.css：选中文字气泡、上下文读音、手动查字、移动端及动态页面内容支持。
- dictionary-data.js：14809个汉字的精简释义和48个原创课堂词语释义；课程用字的部分释义为本项目原创简释。其余字义来自 pwxcoo/chinese-xinhua 的开源数据，不代表商业新华字典的官方服务。MIT 许可证保存在 vendor/chinese-xinhua-LICENSE.txt；源仓库 https://github.com/pwxcoo/chinese-xinhua ，构建数据对应源提交 `fe6d6c2e8baa82187f4c96bbe042e43f96c05666`。
- writing-guide.js、writing-guide.css：课程讲解图、可点击故事山、按内容展开的词句库、分支连接和纸上标记提示。
- mindmap.js、mindmap.css：写作阶段的结构图、三条主枝、重点内容子枝及手机/打印布局。
- vendor/pinyin-pro-3.29.4.js：本地拼音词库（MIT）；许可证为 vendor/pinyin-pro-LICENSE.txt。来自 npm 官方包 https://registry.npmjs.org/pinyin-pro/-/pinyin-pro-3.29.4.tgz 。文档 https://pinyin-pro.cn/use/pinyin.html 。按整段文字识别多音字，不逐字孤立猜读；用户自填的输入框内容不修改。
- serve.cjs：零依赖本地预览服务器，仅监听本机。
- verify.cjs：关键流程检查，运行 `node verify.cjs`。
- verify-catalog.cjs：目录版本、切换、素材隔离和猜人物规则检查。
- verify-courses.cjs：遍历45个非旧人物训练入口，检查全部课程的完整内容、步骤门槛、判断纠错、自画像2—3特点、保存恢复、重置及异常数据。
- verify-guide.cjs：三上讲解与所有内容选项/子枝、词句卡门槛、水边四季切换与关联清理、末位季节恢复、字数对应和故事山导航。
- verify-reading-map.cjs：页面用字释义覆盖、离线依赖、上下文读音、取消整页注音、导图分组、顺序、素材显示和转义检查。

学习记录只保存在当前浏览器，不跨设备同步。没有账号和作文评分。所有已列目录都有完整训练；修订版下册的题目顺序仍未核对，暂不开放该版本下册。示例图画用自编文字情境，不替代纸质课本图画。文化遗产范例用于演示资料整理方法，孩子仍需查询所选地点的具体资料。

## 检查

依次运行 `node verify.cjs`、`node verify-catalog.cjs`、`node verify-courses.cjs`、`node verify-reading-map.cjs`、`node verify-guide.cjs`。浏览器检查目录进入课程、步骤选择、判断纠错、刷新恢复、导图回看、选中文字查询、普通点击不弹字典、字典关闭、多音字和手机布局。
